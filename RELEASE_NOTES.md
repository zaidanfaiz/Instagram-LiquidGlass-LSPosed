# Instagram Liquid Glass v0.1.0-beta.1

**First beta release** of the floating frosted-glass navbar for Instagram via LSPosed.

### Highlights
- Floating **Home · Reels · DM · Profile** capsule and separate **Search** button.
- Tap, drag and best-effort swipe order: **Home → Reels → DM → Profile → Search**.
- Frosted background on main pages, experimental **Reels video blur**, contextual hiding and bottom-spacing fixes.

### Device tested
**POCO F7 Ultra** · **Android 16 (API 36)** · **Instagram 452.0.0.48.64** · recorded window **1440 × 3200**.

Other Android/Instagram versions **may work**; they have not all been verified. Requires LSPosed.

### Install & update
Download the attached **APK**, enable it for **Instagram** in LSPosed, then force-stop and reopen Instagram. Future updates are **manual via GitHub Releases → APK → Android Update** (when signing certificates match).

> **Beta notes:** Video blur is an Android sampling effect, not native iOS refraction. This APK uses CI debug signing, so a future update may require reinstalling **the module only**. No modified Instagram APK is included.
